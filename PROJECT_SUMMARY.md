## 🚀 How to Use

### Quick Start
```bash
cd pygame-projects
python game_launcher.py
```

### Selecting Games
1. Click on any game card
2. Card animates and launches game
3. Press ESC to return to launcher

### Controls by Game
- **Flappy Bird**: SPACE to flap
- **Snake**: Arrow keys to move
- **Pong**: UP/DOWN (P1), W/S (P2)
- **Monster Run**: SPACE to jump
- **Space Invaders**: Arrows + SPACE to shoot
