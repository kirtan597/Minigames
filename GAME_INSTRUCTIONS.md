# 🎮 Minigames Central - Complete Guide

Welcome to **Minigames Central**, a unified gaming platform featuring 5 exciting pygame games!

## 🎯 How to Play

### 1. **Flappy Bird** 🐦
- **Objective**: Navigate the bird through pipes without hitting them
- **Controls**: 
  - `SPACE` - Make the bird flap/jump
  - `ESC` - Return to launcher
- **Tips**: 
  - Tap gently for smooth movement
  - Time your flaps carefully
  - Perfect for children - smooth and relaxing!

### 2. **Snake Game** 🐍
- **Objective**: Grow your snake by eating apples while avoiding hitting walls or yourself
- **Controls**:
  - `ARROW KEYS` - Move the snake (Up, Down, Left, Right)
  - `ESC` - Return to launcher
  - `Q` - Quick exit
- **Tips**:
  - Plan ahead to avoid trapping yourself
  - Each apple adds 10 points
  - The snake starts slowly for easy gameplay

### 3. **Pong Game** 🏓
- **Objective**: Classic Pong action! Move your paddle to hit the ball past your opponent
- **Controls**:
  - **Player 1 (Right)**: `UP` and `DOWN` arrows
  - **Player 2 (Left)**: `W` and `S` keys
  - `ESC` - Return to launcher
- **Tips**:
  - First to score wins!
  - Keep your paddle centered
  - Predict ball trajectory

### 4. **Monster Run** 👾
- **Objective**: Run as long as possible while avoiding flying and ground obstacles
- **Controls**:
  - `SPACE` - Jump
  - `ESC` - Return to launcher
- **Tips**:
  - Time your jumps carefully
  - Score increases over time
  - Smooth physics for child-friendly gameplay

### 5. **Space Invaders** 👽
- **Objective**: Defend your spaceship! Shoot down alien invaders before they reach you
- **Controls**:
  - `LEFT` / `RIGHT` arrows - Move your spaceship
  - `SPACE` - Fire bullets
  - `ESC` - Return to launcher
- **Tips**:
  - More enemies in widescreen for extra challenge
  - Dodge incoming fire
  - Collect points by destroying aliens

## 🚀 Quick Start

1. Run the launcher:
   ```
   python game_launcher.py
   ```

2. Click on any game card to start playing

3. Press `ESC` to return to the launcher anytime

4. Click `X` or press `ESC` on launcher to quit

## 🐛 Troubleshooting

**Games won't launch?**
- Ensure you're in the correct directory
- Check Python path is correct
- Verify all game files are present

**Graphics look stretched?**
- Check your display resolution
- Games are optimized for 1280x720

**Controls not working?**
- Ensure the game window has focus
- Check your keyboard isn't locked
- Try restarting the game
